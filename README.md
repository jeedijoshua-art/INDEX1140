## 🛠️ Technologies Used
This entire portfolio and its sub-projects were built using the following core frontend technologies:
* **HTML5:** For semantic structuring of web content.
* **CSS3:** For custom layouts, color schemes, and visual styling.
* **JavaScript (JS):** For adding dynamic behavior, interactivity, and logic.
* **Bootstrap:** For implementing a mobile-first, responsive grid system and modern UI components cleanly.
